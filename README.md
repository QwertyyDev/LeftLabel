# LeftLabel

Velocity plugin that shows a configurable MiniMessage label on the server list next to the server icon.

## Features

- MiniMessage support
- Velocity proxy support
- Java 21
- Custom server list label (left-of-icon style)
- Compatible with other MOTD plugins
- Lightweight and fast

## Commands

- /leftlabel reload → Reloads config
- /leftlabel toggle → Enables or disables the label

## Config

label: "<gradient:gold:yellow>Bize Katıl »</gradient>"
enabled: true

## Notes

- Does not override backend MOTD
- Only modifies server list visual output
- Fully compatible with modern Velocity versions
